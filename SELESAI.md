## 🎯 **SIAP DEPLOY KE RAILWAY**

### **Langkah-langkah:**
1. **Push ke GitHub**
   ```bash
   git add .
   git commit -m "Initial commit - KyyStatus HD"
   git remote add origin https://github.com/your-username/kyystatus-hd.git
   git push -u origin main
   ```

2. **Import ke Railway**
   - Buka https://railway.app
   - Click "New Project" → "Deploy from GitHub repo"
   - Pilih repository Anda

3. **Set Environment Variables**
   ```
   NODE_ENV=production
   PORT=3000
   HOST=0.0.0.0
   CORS_ORIGIN=*
   SESSION_DIR=/data/sessions
   STORAGE_DIR=/data/storage
   TEMP_DIR=/data/temp
   ```

4. **Add Volume**
   - Buka tab "Volumes"
   - Buat volume baru bernama `data`
   - Mount path: `/data`

5. **Deploy!**
   - Click "Deploy"
   - Tunggu sampai build selesai
   - App siap digunakan!
